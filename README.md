# miqra-web

Public web property for **Miqra — Tanakh** · **miqra.khassinx.com**.

A reverent Tanakh reader with an on-device, non-generative concordance (it surfaces
connections; it never interprets). Public-domain text, privacy-first. For iPhone, iPad,
Mac, and Apple Watch. Part of the KhassinX ecosystem.

- **Stack:** Jekyll (GitHub Pages), EN default + ES under `/es/`.
- **Brand/SEO/security:** per `KhassinX` web canon (CSP, security.txt RFC 9116, JSON-LD,
  hreflang, PWA/A2HS, og 1200×630).
